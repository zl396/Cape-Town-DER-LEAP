# LEAP Implementation Guide: S3 Progressive Subsidy Scenario

## Overview

This guide provides step-by-step instructions for building the **S3 Progressive Subsidy** scenario in the LEAP model (`capetown_07072025.leap`). S3 models targeted, income-scaled subsidies for SHS (Solar Home System) adoption, where low-income households receive the largest subsidy and high-income households receive none.

**Prerequisites:**
- LEAP/NEMO software installed (Windows)
- `capetown_07072025.leap` model file open in LEAP
- `S3_scenario_assumptions.xlsx` (generated by the Bass diffusion model script)
- `s3_bass_diffusion_results.csv` (raw data output)

---

## Step 1: Create the S3 Scenario

1. Open `capetown_07072025.leap` in LEAP
2. Navigate to **Analysis → Manage Scenarios** (or click the Scenarios button in the toolbar)
3. Click **Add** to create a new scenario
4. Configure:
   - **Name:** `S3 Progressive Subsidy`
   - **Inherit from:** `Business-As-Usual (BAU)`
   - **Description:** *"Targeted progressive subsidy for low- and middle-income SHS adoption. Low-income receives the largest subsidy, middle-income receives moderate subsidy, high-income receives no additional incentive. Adoption rates projected using Bass Diffusion Model."*
5. Click **OK** to create the scenario

> **Important:** Because S3 inherits from BAU, all BAU assumptions (supply, demand, tariffs, growth rates) carry over. You only need to modify the SHS adoption rates and SSEG capacity.

---

## Step 2: Demand Side — Modify High-Income Adoption

**No changes needed.** High-income SHS adoption in S3 is the same as BAU (no additional subsidy for high-income). The scenario inherits these values automatically.

> If you later want to verify, navigate to:
> `Demand → Households → Electrified → High Income → Grid and SHS`
> and confirm the Activity Level share matches BAU.

---

## Step 3: Demand Side — Modify Middle-Income Adoption

The BAU scenario has middle-income SHS adoption reaching 20% by 2040. Under S3, the moderate progressive subsidy increases adoption to **25% by ~2042**.

### 3.1 Navigate to Middle-Income Branch
1. In the LEAP tree view, expand: **Demand → Households → Electrified → Middle Income**
2. If a **"Grid and SHS"** sub-branch exists, click on it
3. If it does NOT exist, right-click on "Middle Income" → **Add Branch** → Name it "Grid and SHS"

### 3.2 Input Adoption Rates
1. Make sure you are in the **S3 Progressive Subsidy** scenario (check the scenario selector at the top)
2. Click on the **Activity Level** for the "Grid and SHS" branch
3. Select **Expression Type: Interpolation** (this allows year-by-year input)
4. Enter the adoption rates from `S3_scenario_assumptions.xlsx` → Sheet "Adoption Rates" → column "MI Adoption (%)"

**Key values to input (% of middle-income HH with SHS):**

| Year | MI Adoption (%) |
|------|-----------------|
| 2024 | 0.52 |
| 2025 | 1.17 |
| 2026 | 2.22 |
| 2027 | 3.79 |
| 2028 | 5.93 |
| 2029 | 8.52 |
| 2030 | 10.52 (≈11%) |
| 2035 | 20.24 (≈20%) |
| 2040 | 24.37 (≈24%) |
| 2045 | 24.93 |
| 2050 | 24.99 (≈25%) |

> **Tip:** You can input just the milestone years (2024, 2025, 2030, 2035, 2040, 2045, 2050) and LEAP will interpolate between them. Or input all years from the CSV for maximum precision.

### 3.3 Update "Grid Only" Branch
Since "Grid and SHS" adoption increases, the "Grid Only" share must decrease correspondingly:
- **Grid Only share = 100% - Grid and SHS share**
- Use: `Remainder(100)` expression in LEAP for the "Grid Only" Activity Level

### 3.4 Set Energy Intensity for Middle-Income SHS Households
For the "Grid and SHS" technology branch:
- **Grid consumption:** 5,020 kWh/HH/year (from report Table 8)
- **SHS consumption:** 1,326 kWh/HH/year
- Use the same values as the existing model or verify against `S3_scenario_assumptions.xlsx` → Sheet "Energy Parameters"

## Step 4: Demand Side — Create Low-Income SHS Branch

The BAU scenario has **0% low-income SHS adoption**. Under S3, the largest progressive subsidy enables **15% adoption by ~2045**.

### 4.1 Create the Branch Structure
1. Navigate to: **Demand → Households → Electrified → Low Income**
2. Right-click on "Low Income" → **Add Branch**
3. Name it: **"Grid and SHS"**
4. Set the technology type to match the existing high-income "Grid and SHS" setup

### 4.2 Input Adoption Rates
1. Ensure you are in the **S3 Progressive Subsidy** scenario
2. Click on **Activity Level** for the new "Grid and SHS" branch
3. Set **Expression Type: Interpolation**
4. Enter values from `S3_scenario_assumptions.xlsx` → "LI Adoption (%)"

**Key values to input (% of low-income HH with SHS):**

| Year | LI Adoption (%) |
|------|-----------------|
| 2024 | 0.93 |
| 2025 | 2.08 |
| 2026 | 3.41 |
| 2027 | 4.85 |
| 2028 | 6.17 |
| 2029 | 7.25 |
| 2030 | 7.25 (≈7%) |
| 2035 | 12.36 (≈12%) |
| 2040 | 14.29 (≈14%) |
| 2045 | 14.87 |
| 2050 | 14.96 (≈15%) |

### 4.3 Update "Grid Only" Branch
- Set the "Grid Only" Activity Level to: `Remainder(100)`
- This ensures Grid Only = 100% - Grid and SHS

### 4.4 Set Energy Intensity for Low-Income SHS Households
For the new "Grid and SHS" branch:
- **Grid consumption:** 3,303 kWh/HH/year (85% of total low-income avg)
- **SHS consumption:** 584 kWh/HH/year (15% self-sufficiency)
- **Total:** 3,887 kWh/HH/year (same as low-income average)

> **Note:** The 15% SHS self-sufficiency for low-income is based on the RES4Africa baseline for smaller systems (3 kW). This can be adjusted if your model uses different assumptions.

## Step 5: Supply Side — Update SSEG Capacity

The increased residential SHS adoption under S3 must be reflected in the supply-side SSEG capacity.

### 5.1 Navigate to SSEG
1. Expand: **Transformation → Distributed Generation → SSEG**
2. Ensure you are in the **S3 Progressive Subsidy** scenario

### 5.2 Input New Capacity Values
The total SSEG capacity under S3 includes:
- Residential SHS from all three income groups (from Bass model)
- Commercial SSEG (LPU/SPU) at BAU rates

Use values from `S3_scenario_assumptions.xlsx` → Sheet "SHS Capacity" → column "S3 Total SSEG (MW) est."

**Key capacity milestones:**

| Year | Residential SHS (MW) | Est. Commercial (MW) | Total SSEG (MW) |
|------|---------------------|---------------------|-----------------|
| 2024 | ~120 | ~39 | ~159 |
| 2025 | ~155 | ~42 | ~197 |
| 2030 | ~522 | ~54 | ~576 |
| 2035 | ~741 | ~80 | ~821 |
| 2040 | ~893 | ~117 | ~1,010 |
| 2045 | ~976 | ~172 | ~1,148 |
| 2050 | ~1,033 | ~253 | ~1,286 |

### 5.3 Input Method
1. Click on **Exogenous Capacity** for the SSEG branch
2. Use **Interpolation** expression type
3. Enter the total SSEG capacity values year by year
4. LEAP will use these capacity values with the capacity factor (19.6%) to calculate generation

---

## Step 6: Verify and Run

### 6.1 Cross-Check Demand and Supply
Before running the model:

1. **Demand check:** Verify that the total residential electricity consumption from SHS (demand side) is approximately consistent with the SSEG generation (supply side)
   - Demand-side SSEG consumption = Σ (HH with SHS × SHS energy intensity) for each income group
   - Supply-side SSEG generation = SSEG capacity (MW) × capacity factor (19.6%) × 8,760 hours

2. **Activity level check:** Ensure "Grid Only" + "Grid and SHS" = 100% for each income group

### 6.2 Run the Model
1. Go to **Analysis → Calculate** (or press F5)
2. Select the S3 scenario
3. Set calculation period: 2024-2050
4. Run the calculation

### 6.3 Review Results
Compare S3 against BAU:

1. **Load Shedding (Unmet Requirements):**
   - Go to **Results → Transformation → Unmet Requirements**
   - S3 should show reduced load shedding compared to BAU (more SSEG capacity)

2. **Energy Balance:**
   - Check **Results → Energy Balance** for 2030, 2040, 2050
   - Verify SSEG contribution increases over time

3. **Demand by Income Group:**
   - Check **Results → Demand → Households → Electrified → [Income Group]**
   - Verify SHS consumption appears for middle and low income

4. **Sankey Diagrams:**
   - Go to **Results → Sankey** for visual energy flow checks
   - Compare 2024 vs 2050 energy flows

5. **Cost Analysis (if available):**
   - Check affordability impacts under **Results → Social Accounting**

## Troubleshooting

### Common Issues

**Issue: SSEG generation exceeds demand-side SHS consumption**
- This means supply-side capacity is too high relative to demand-side adoption
- Reduce the SSEG capacity values, or increase the SHS self-sufficiency ratios

**Issue: Negative generation or impossible values**
- Check that all input values are positive
- Verify that the capacity factor is set correctly (19.6%)
- Ensure "Grid and SHS" adoption rates don't exceed 100%

**Issue: Low-income "Grid and SHS" branch not appearing**
- Make sure the branch was created under the correct scenario (S3, not BAU)
- Check that the Activity Level expression is set correctly

**Issue: Results identical to BAU**
- Verify you are viewing the S3 scenario (check scenario selector)
- Confirm that the S3 scenario was set to inherit from BAU
- Check that you modified values in the S3 scenario, not in BAU

| Component | BAU | S3 Progressive Subsidy |
|-----------|-----|----------------------|
| HI SHS adoption (2050) | ~30% | ~30% (no change) |
| MI SHS adoption (2050) | ~20% | ~25% |
| LI SHS adoption (2050) | 0% | ~15% |
| LI "Grid and SHS" branch | Does not exist | Created new |
| Total residential SHS (2050) | ~540 MW (HI only) | ~1,033 MW (HI+MI+LI) |
| SSEG capacity (2050) | BAU value | ~1,286 MW (with commercial) |
